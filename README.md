# Guia UTI Neonatal - Mackenzie UEMS

Guia prático e material de apoio para a Unidade de Terapia Intensiva Neonatal (Mackenzie / UEMS).

## 📌 Sobre o Projeto

Este repositório contém a documentação, especificações e materiais do Guia de UTI Neonatal desenvolvido em parceria Mackenzie / UEMS.

## 🛠️ Estrutura do Repositório

- `.specify/`: Modelos, fluxos de trabalho e constituição de especificações de features.
- `.agents/`: Habilidades (skills) e ferramentas para assistência de desenvolvimento automatizado.
